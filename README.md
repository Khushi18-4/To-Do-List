# To-Do-List
A vibrant, neon-rainbow themed client-side To-Do List app built with vanilla JS. Features full CRUD, state-driven UI, Local Storage, and event delegation.
## 🌈 About The Project

**Task Fusion** is a state-driven, client-side To-Do List application designed with an energetic **Rainbow Glow / Neon Cyberpunk** aesthetic. This project focuses heavily on mastering modern JavaScript fundamentals, advanced DOM manipulation, and efficient memory management.

Instead of relying on heavy frameworks, it utilizes pure Vanilla JavaScript to deliver a snappy, fluid, and visually stunning user experience that retains data across browser reloads.

### ✨ Key Features

- **Full CRUD Functionality:** Seamlessly Create, Read, Update (inline editing), and Delete tasks in real-time.
- **State Data Persistence:** Automatically syncs and persists user data using `window.localStorage`.
- **Advanced Spectrum Filtering:** Instant layout switching between **All**, **Active**, and **Completed** tasks using custom predicate filters.
- **High-Performance Architecture:** Implements **Event Delegation** on a single root listener to minimize memory overhead for dynamic list elements.
- **Futuristic Rainbow UI:** Features a dynamic CSS-animated gradient header, custom prismatic checkboxes, and a premium high-contrast dark mode surface.

### 🛠️ Tech Stack Used

- **HTML5** (Semantic layout structure)
- **CSS3** (CSS Variables, Keyframe Animations, Glassmorphic effects)
- **JavaScript (ES6+)** (State Management, DOM Injection, LocalStorage API)
